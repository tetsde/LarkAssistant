Nhập App ID và App Secret để HiLark xác thực ứng dụng trước khi mở luồng ủy quyền.
Cấp phát theo tenant
Tenant access token được dùng để tạo Base, cấu hình dữ liệu và khởi tạo không gian WeKnora riêng.
OAuth user là bắt buộc
Admin tiếp tục cấp quyền user để HiLark nhận access token, refresh token và gửi đúng hành động dưới danh nghĩa người dùng.
