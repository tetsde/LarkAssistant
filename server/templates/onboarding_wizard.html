Kết Nối Lark Bot & Hạ Tầng Điều Hành

Chào mừng {{effective_user_name}} đến với HiLark. Thiết lập danh tính trợ lý AI trên Lark Developer và cấu hình cổng giao tiếp cho doanh nghiệp.

Hướng dẫn tạo Bot trên Lark Developer Portal (2 phút)
Xem chi tiết ▾
1. Tạo ứng dụng: Mở Lark Developer Console ↗ và nhấn Create Custom App.
2. Bật tính năng Bot: Vào menu Add Features ở thanh bên trái → Bấm Add tại mục Bot.
3. Chọn chế độ WebSocket: Vào Events & Callbacks, mục Connection Method chọn Long Connection (WebSocket) để nhận tin trực tiếp, không cần mở port mạng.
4. Phát hành ứng dụng: Vào Version Management & Release → Bấm Create a version và Publish.
5. Lấy khóa kết nối: Mở mục Credentials & Basic Info, sao chép App ID và App Secret dán vào form bên dưới.
